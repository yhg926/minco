# Artifacts

- `NOTE.md`: result interpretation and headline tables.
- `commands.sh`: reproducible commands.
- `score_source_ref_ani.py`: source/ref pairing and skani scoring.
- `score_alternative_read_ani.py`: alternate read-ANI metric scoring.
- `selected_calls_input.tsv`: selected Sylph and MinCO calls used as inputs.
- `source_genome_read_counts.tsv`: CAMI3 source genome read counts by sample and taxid.
- `source_genome_paths.tsv`: resolved source genome FASTA paths.
- `call_source_candidates.tsv`: candidate source genomes per selected call.
- `call_source_candidates_with_skani.tsv`: candidate sources annotated with skani source/ref ANI.
- `source_ref_skani_pairs.tsv`: cached skani pairwise ANI results.
- `read_vs_source_ref_ani_detail.tsv`: selected read-major and best-ANI source pairings.
- `summary.tsv`: selected-pred-ANI summary.
- `alternative_read_ani_summary.tsv`: main Sylph adjusted/naive and MinCO ZIP/emitted/naive ANI summary.
- `diagnostics.tsv`: counts for selected calls, resolved sources, and skani pairs.
