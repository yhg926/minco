# Artifacts

- `run_switch_validation.py`: runs the implemented switch from saved unique/split tables and scores actual wrapper output.
- `results/switch_profile_runtime.tsv`: exact commands, elapsed time, and peak RSS.
- `results/switch_profile_scores.tsv`: per-sample GTDB scores.
- `results/switch_profile_panel_summary.tsv`: panel-level metric rollup.
- `results/switch_profile_overall_summary.tsv`: overall rollup copied to `summary.tsv`.
- `results/switch_profile_added.tsv`: rows added by the implemented switch.
- `/tmp/minco_profile_rescue_switch_implementation_validation_20260701`: temporary large profile outputs.
